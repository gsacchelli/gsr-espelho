# Framework Relacionado

## Objetivo
Servir como ponto de conexão entre frameworks estratégicos utilizados no sistema.

---

## O que são frameworks

Frameworks são estruturas que ajudam a:
- organizar pensamento  
- analisar problemas complexos  
- tomar decisões com lógica

## Como usar

Ao analisar qualquer problema:

1. Identificar qual tipo de problema é  
2. Escolher o framework adequado  
3. Aplicar com profundidade  
4. Conectar com decisão

## Insight chave

Framework não substitui pensamento.
