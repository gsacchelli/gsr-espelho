# VRIO

## Definição
Framework para avaliar se um recurso gera vantagem competitiva sustentável.

---

## Estrutura

1. **Value (Valor)**
O recurso gera valor real para o cliente ou reduz custo?

2. **Rarity (Raridade)**
É raro no mercado?

3. **Imitability (Imitabilidade)**
É difícil de copiar?

4. **Organization (Organização)**
A empresa consegue explorar esse recurso?

---

## Interpretação

- Não valioso → desvantagem
- Valioso mas comum → paridade competitiva
- Valioso + raro → vantagem temporária
- Valioso + raro + difícil de copiar + bem organizado → vantagem sustentável

---

## Aplicação prática

Avaliar:
- equipe comercial
- relacionamento com clientes
- acesso a fornecedores
- tecnologia
- marca

---

## Insight chave

Muitos recursos são valiosos, poucos são raros, raríssimos são difíceis de copiar.
